# 技术总结

记录工作和学习中的技术要点。

## Git常用命令
| 命令 | 功能 |
|------|------|
| `git init` | 初始化仓库 |
| `git add .` | 添加所有文件到暂存区 |
| `git commit -m "备注"` | 提交暂存区到本地仓库 |
| `git push` | 推送到远程仓库 |
| `git pull` | 拉取远程仓库更新 |

## GitHub Pages部署注意事项
1. 仓库名必须是 `用户名.github.io`（如果是个人主页），或任意名称（如果是项目页）
2. 部署分支选择 `main` 或 `master`，目录选择根目录（/）
3. 推送后需等待1-2分钟生效，可在仓库 Settings → Pages 查看部署状态
4. 本地预览需用 Live Server 插件，避免跨域问题

## 前端基础知识点
- HTML：结构层，负责页面内容
- CSS：样式层，负责页面美观
- JavaScript：行为层，负责页面交互
- Markdown：轻量级标记语言，适合写笔记和文档
