# 制作网站笔记

## 一、技术选型
### 1. 核心技术栈
- 前端：HTML5 + CSS3 + JavaScript（原生开发，无框架依赖）
- 渲染引擎：marked.js（Markdown转HTML）
- 部署平台：GitHub Pages（免费托管，全球访问）
- 版本控制：Git + GitHub（代码管理+自动部署）

### 2. 功能实现清单
| 功能 | 实现方式 | 关键代码 |
|------|----------|----------|
| 多级目录 | 递归渲染+JSON索引 | renderTreeNodes() 函数 |
| 笔记搜索 | 内容缓存+关键词匹配 | 预加载笔记内容+防抖搜索 |
| 明暗模式 | CSS变量+本地存储 | :root变量+localStorage |
| 自动索引 | GitHub Actions + 本地脚本 | generate-index.js |

## 二、部署步骤
1. 创建GitHub仓库（命名任意，如 `notes`）
2. 编写核心文件（index.html、style.css、main.js）
3. 配置GitHub Pages（Settings → Pages → 选择main分支）
4. 启用自动索引（添加.github/workflows/generate-index.yml）
5. 推送代码：`git add . → git commit -m "初始化网站" → git push`

## 三、常见问题解决
### 1. 索引文件未生成
- 检查Actions权限（需Read and write permissions）
- 确认notes文件夹下有.md文件
- 手动运行脚本：`node generate-index.js`

### 2. 网站加载缓慢
- 优化图片大小（使用压缩工具如TinyPNG）
- 减少CDN依赖（仅保留必要的marked.js和font-awesome）
- 避免大文件笔记（单篇笔记建议<10MB）

## 四、优化方向
- 增加笔记标签功能（分类管理）
- 支持笔记导出（PDF/HTML格式）
- 添加评论系统（基于GitHub Issues）
