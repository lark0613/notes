# 使用AI工具帮助开发的笔记

## 一、代码开发类工具
### 1. GitHub Copilot
- 功能：实时代码补全、语法纠错、生成注释
- 使用场景：
  - 快速生成重复代码（如循环、条件判断）
  - 转换代码格式（如JSON转Python字典）
  - 解释复杂代码（选中代码→Ask Copilot）
- 快捷键：
  - 接受补全：Tab
  - 触发建议：Alt+\（Windows）/ Option+\（Mac）

### 2. ChatGPT 4o
- 核心用途：
  - 技术方案设计（如"设计一个笔记网站的数据库结构"）
  - 调试代码（粘贴报错信息→获取解决方案）
  - 学习新技术（如"用通俗的语言解释React Hooks"）
